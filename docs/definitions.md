## Definition of Ready
- [ ] Задача имеет четкое описание и acceptance criteria
- [ ] Дизайн утвержден (для UI задач)
- [ ] Технический анализ проведен
- [ ] Оценка времени выполнения
- [ ] Зависимости определены
- [ ] Тестовые данные подготовлены

## Definition of Done
- [ ] Код написан и проходит code review
- [ ] Unit tests написаны и проходят
- [ ] Integration tests проходят
- [ ] Документация обновлена
- [ ] UI соответствует макетам
- [ ] Performance требования выполнены
- [ ] Безопасность проверена

## Product Metrics
- **North Star**: Weekly Active Users (WAU)
- **Вовлеченность**: Количество обработанных встреч на пользователя
- **Качество**: Точность извлечения action items (>85%)
- **Производительность**: Время обработки встречи < 15 минут

## Technical Metrics
- **Availability**: 99.5% uptime
- **Performance**: API response time < 2s (p95)
- **Reliability**: Error rate < 1%
