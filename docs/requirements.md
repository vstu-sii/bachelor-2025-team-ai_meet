## Core Functionality
- **F001**: Автоматическая транскрипция аудио встреч
  - Поддержка форматов: MP3, WAV, MP4
  - Максимальная длительность: 4 часа
  - Поддержка языков: русский, английский

- **F002**: NLP анализ для извлечения сущностей
  - Выделение решений
  - Извлечение задач
  - Определение ответственных
  - Выявление сроков

## Производительность
- **NFR001**: Время обработки 1 часа аудио ≤ 15 минут
- **NFR002**: Доступность системы: 99.5% (SLA)
- **NFR003**: Одновременная обработка: 100+ встреч
- **NFR004**: Задержка ответа API ≤ 2 секунд

## Безопасность
- **SEC001**: Шифрование данных в rest и transit
- **SEC002**: GDPR compliance для аудио данных
- **SEC003**: Авторизация на основе JWT токенов
